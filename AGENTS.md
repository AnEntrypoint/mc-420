# Resonode and the granulator

- Hot-deploy the WHOLE `.lv2` bundle (`.so` AND `.ttl`): a stale `.ttl` mismatches LV2 port indices; the plugin faults on first process and silently disables itself.
- Measure, never guess: `tools/resonode-lab/` compiles `resonode_synth.dsp` with the pinned flags and reports peak/RMS/crest/clip/sat, centroid, 4 band ratios, Goertzel f0, transient+sustain, decay.
- Excitation bus is `sharedExciteIn*input + internalExciter*(1-input)`; `mallet`/`bow` split a `hardness`-shaped noise source between struck and sustained envelopes, so a held key sounds with no input.
- Per-partial `modeDecayScale(i)`/`modeAmpBase(i)` (blended like `modeRatio(i)`) give each material its own decay+gain curve. `highFreqDampExponent` stays `1.0*(1-damping)`, NOT `1.934264*(-log(damping))/log(2)` (8.35 collapsed Dance Bass to one partial). `impactSig` (0.6-14 ms by `hardness`) sits OUTSIDE `excEnv`, scaled by `(1-inputAmt)` so `input=1` stays bit-exact.
- `collisionDrive` normalises by `1/driveAmt`, never `1/tanh(driveAmt)` (a +17 dB make-up gain at collision=1, why patches differed ~13 dB). Scaled by `drivePreGain = outLevel*decayLoudnessNorm` and divided back out: the pre-gain signal is ~25x smaller and tanh there is linear. Collision is a compressor: raising it LOWERS peak, crest and first-diff RMS; `verify_musical_controls.py`'s collision=0 identity check strips `collisionDrive(` by paren matching, not a literal signature.
- Each voice drives a waveguide Object stage (tuned feedback comb; `body` mix, `polarity` sign, `g = 0.001^(1/(T60*f0))`, peak normalised by `1-g`, 25 Hz highpass kills DC). Positive polarity is bassier (0.8194 vs 0.7996 low-band, note 36).
- The granulator is `Sampler`, NOT `effects/home/faust/grainFormant.h` (only the SOLA shifter's formant layer). Each grain reads the key's captured buffer or a 2.7 s live ring, chosen per grain by `liveMix`; `Grain::wrap` makes ring grains wrap instead of dying at the edge. Without the ring it is silent until something is captured. Freeze = the scan dial's bottom eighth; `scanRate=0` is NOT a freeze.
- No L/R bus: ch0 master, ch1 cue, mono floats. `lv2_host` disables plugins wanting >1 audio port per direction.

image/config/usercfg.txt (Pi4 boot config additions, appended to config.txt/usercfg.txt): dtoverlay=dwc2,dr_mode=peripheral puts the USB-C/OTG port into gadget mode for f_uac2 (matches AGENTS.md's documented pi4 USB-audio-gadget support). enable_uart=1 turns on the serial console on the GPIO UART (GPIO14 TX / GPIO15 RX, 115200 8N1, pinout in docs/FLASHING.md) specifically so first boot/bring-up is debuggable from a card without an HDMI display attached -- not otherwise documented in AGENTS.md. The image build merges kernel/cmdline.txt (RT-tuned isolcpus etc.) into the boot cmdline separately from this file.

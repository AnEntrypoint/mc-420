resonode_synth.dsp modeCount is capped by Faust COMPILE time, not only by CPU. At 24 modes with the Chebyshev position-sine in place, the real faust compiler is killed by SIGALRM about two minutes into the -i -a lv2.cpp codegen: build-lv2 fails with exit code 142 and the shell logs "Alarm clock" against the faust invocation. Diagnose with gh run view <id> --log-failed and ignore the CLI-echo lines; the useful line is the shell reporting Alarm clock. This is the documented compile-time cliff for this file, reproduced rather than assumed. Measured ladder on a real Pi 4 (eight-key stress, peak core_busy / diag-gap count, all zero xruns): 12 modes ~73% / 2-3, 16 modes 70-73% / 5-7, 20 modes 82-85% / 8-13, 24 will not build. Ships at 16. The ratio tables stay 24 entries because ba.take is index-safe, so modeCount is a single reversible constant on line 8.

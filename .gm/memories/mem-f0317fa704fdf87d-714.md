A manual 'bash image/build-netboot.sh' passing only LV2_DIR silently ships a boot tree with NO Resonode, PitchTracker or DelayVerb bundle -- lib-boot-tree.sh reads RESONODE_LV2_DIR, PITCHTRACKER_LV2_DIR and DELAYVERB_LV2_DIR as separate env vars since those are excluded by name from the general LV2_DIR find. It warns on stdout but still produces a complete-looking apkovl, so the failure is easy to miss. serve-netboot-win.js passes all four correctly, so the safest manual rebuild is to delete .netboot-update-sha and let the server rebuild itself. Verify: tar -tzf .netboot-serve/aloop.apkovl.tar.gz | grep -oE 'effects/[a-z]+/[a-z_]+.lv2' | sort -u -- expect delayverb, guitar_lofi_fx, pitchtracker, resonode.

test/hardware/midi-inject.js -- byte-level MIDI injection tool referenced by AGENTS.md's working rules (tcp/9401, src/control/midi.cpp) but AGENTS.md doesn't give its actual CLI syntax; worth a one-line addition there. Usage: node midi-inject.js <host> note-on <note> <velocity> [channel=0] | note-off <note> [velocity=0] [channel=0] | cc <controller> <value> [channel=0] | raw <hex-bytes...> (e.g. raw 90 02 7f) | hold <note> <ms> [channel=0] (note-on, wait ms, note-off). Separately, a general Node.js gotcha found while building it: a bare net.connect() with no explicit timeout can hang for the OS's own default TCP connect timeout (well over a minute on Windows) against an unreachable host. sock.setTimeout() bounds this, but Node's 'timeout' event fires WITHOUT closing the socket (documented Node behavior) -- the socket must be destroyed manually in the timeout handler to force the reject path, or the hang persists past the intended timeout anyway.

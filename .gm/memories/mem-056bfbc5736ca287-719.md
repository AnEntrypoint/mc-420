image/aloop-logtail.js streams aloop's on-device log (/var/log/aloop.log, OpenRC output_log/error_log) to the dev host live, by polling a LOGTAIL verb on the SAME udp/4446 remote-control listener that serves REBOOT (src/control/remote_control.cpp, token-authenticated via aloop.conf's [remote] token=, same mechanism AGENTS.md documents for REBOOT:<token>) -- not a syslog protocol, since aloop's stdout/stderr already land in a real file. Usage: node image/aloop-logtail.js --host 192.168.137.100 --token <secret> [--interval 1000], or PI_HOST/PI_TOKEN env vars. Highlights panic/crash/fatal lines. Worth adding a one-line pointer to AGENTS.md's REBOOT:<token> section noting LOGTAIL shares the same udp/4446 listener.

When a dev host has no Faust CLI and no Docker, verify generated-code claims with .github/workflows/faust-codegen-probe.yml (workflow_dispatch only) instead of reasoning from .dsp source. It runs the real faust compiler with the exact shipped flags and classifies every transcendental by whether it lands INSIDE the vectorised per-sample loop. Critical detail: with -fun, compute() itself looks almost clean because the hot code lives in the fun*() helper bodies. Counting only inside compute() gave a false all-clear (4 block-rate pow calls) while the helpers held 299 per-sample transcendentals. Three plausible optimisations were REFUTED by this probe: exp(a*b) rewritten as pow(base,b) got WORSE (576 to 679 calls, because pow expands to log+exp internally); the Chebyshev recurrence applied to the resonator cos(2*pi*f/SR) is exact only for INTEGER mode ratios and errs 5.6e-3 against the bell table; un-gliding the six morph knobs bought 576 to 573, nothing, and would have cost zipper-free knob sweeps.

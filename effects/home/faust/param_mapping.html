Parameter mapping — CC/note → normalized → chain constant

The looper’s effect params arrive as MIDI CC/note values and are normalized before reaching the DSP. effects/home/faust/chain.dsp declares the chain constants (SEMIS/FORMANT/ENGAGED/DELAYAMT/REVAMT/TIME/DIV/MLB/HPCUT/LPCUT/LPRES/LPSLOPE) as compile-time values; the shipped runtime chain dsp/effects_runtime.dsp exposes the same labels as hslider/checkbox/nentry UI controls so targetToZone (src/dsp/audio_thread.cpp:157) can set them live. The normalization below is the control-plane mapping: src/control/midi.cpp (the flat config/controls.conf bindings and the eight intercepted fx-knob CCs) and src/control/apc_grid.cpp (ApcGrid::onFxKnobCC, applyFormantCC, and the k*Targets bank tables). On the Dub page the knob CCs feed the zones below; on the Guitar and LofiFx pages the same CCs feed different targets (see docs/COMMAND-SURFACE.md).

Defaults (the passthrough state): HPCUT=0, LPCUT=1, LPRES=0, LPSLOPE=0, REVAMT=0, DELAYAMT=0, TIME=0.5, FORMANT=0, SEMIS=0, ENGAGED=0, DIV=0, MLB=0 — these match chain.dsp:3-13 and filters.dsp:48-51. The byte-exact passthrough (maxAbs=0) is a recorded witness, not re-run here; there is no THRU/LOOP/MIX default in the shipped chain.

aloop — current-state constraints

Real Pi 4 192.168.137.100, root/aloop; Pi 3B+ netboots from host. aloop is a BEHAVIOR clone of ../looper, never a source clone: never vendor its source, never add LOOPER_DIR/loopMachine.cpp/an effects-bridge shim. DSP = Faust (rwtable + recursive heads).

Working rules

  • No comments in code, ever (C++/.dsp/JS/shell/YAML, config-like .gitignore); one sighting => sweep the file. Exempt: #!, # syntax=docker/dockerfile:1, # shellcheck disable=, commented-out keys recording an option (config/aloop.conf). vendor/ + regenerated Faust output exempt; last sweep 2026-10-06.
  • Never add audio-path latency: ~7 ms block latency must never grow, even temporarily; stop and ask first. Exempt: an engaged wet effect’s own algorithmic latency (ef.transpose, SNAC).
  • No WSL, no Docker here, ever; missing compute => GitHub CI/CD (gh).
  • Test on real hardware, never ask the user to reproduce input: MIDI injection (tcp/9401, test/hardware/midi-inject.js) or SSH. Link needs a real peer: test/hardware/link-peer.cpp, host-built -static with -DLINK_PLATFORM_WINDOWS -D_WIN32_WINNT=0x0601 -DASIO_STANDALONE -lws2_32 -lwinmm -liphlpapi -mthreads. No CLEAN audio ingress reaches dry: AIR 192 input silent (audio_peak.in 0.0002); snd-pcm-oss opens 8000 Hz U8 with NO resampling (~150 xruns/s at 48k; at 8k aloop stalls, tracker caps 166 Hz via MIN_PERIOD=48); snd-aloop tears (below); no aplay/arecord/sox/python3, no alsa-utils apk.
  • snd-aloop ingress WORKS but is jiffies-paced — fatal for click measurement. modprobe snd-aloop -> card 2 Loopback, accepts aloop’s params; wiring off /proc/asound/card2/cable#*: writer plays hw:2,1,0; aloop holding hw:2,0,0 captures. period_size=64 + HZ=250 => ~16 kframes/s (167 s of audio took 522 s = 3.1x slow) and TEARS: 41 discontinuities per 6 s of 220 Hz sine, all on 64-sample boundaries; xruns 125/s, tear rate drifts ~0.25-7/s. Only timer G0 (4000 µs) so timer_source cannot point at a card; unfixable without raising period_size (forbidden). So (1) any click/tear witness through it is INVALID (floor 17 glitches vs host 0, drift ±15 > the effect); (2) a torn stream never sets SNAC’s trusted latch (heldDetNote reseeds to the target each attack), so poly transpose never engages on real corpus — only steady synthetic tones and cello.
  • Injector (musl-static aarch64): CI .github/workflows/build-audio-injector.yml, ubuntu-24.04-arm + alpine:3.20 linux/arm64 — alsa-lib 1.2.12 --enable-static --disable-shared, then gcc -O2 -std=c11 -static vs libasound.a.   • Witness hygiene: a held transpose voice whose target EQUALS the detected note reads as “no shift” — pick distinct targets; rc-service aloop restart between MIDI scenarios (note-offs do not clear a held voice).
  • Telemetry (udp/4445) answers in ~190 ms from the 5 Hz loop; lag JITTERS tens of ms. Rate only by least-squares slope over every poll of a >=20 s watch, skipping ~6 s after FINISH. SLIP = readpos vs master_phase_beats * beatLen from the SAME reply. Replies TEAR (looperReadPos early, masterPhaseBeats later): despike with despikedSpread() (test/hardware/lib/gridlock.js); a torn FIRST poll offsets all later samples.
  • Compiling clean proves nothing: x86_64 A/B passed while aarch64 codegen SIGSEGV’d (-mapp); regenerate real C++ and diff byte-for-byte. Heap-allocate large DSP instances (stack-local AloopEffectDsp faults STATUS_STACK_OVERFLOW). A crash fix can UNMASK a 2nd bug: re-measure the SAME live metrics afterwards.
  • t=<sec>.<ms> logs; WebSearch before irreversible hardware steps; SSH via JS ssh2, never ssh.exe/sshpass. Windows Firewall silently black-holes the Pi: rule it out before debugging netboot/SSH as a device fault.

  • commitAppSessionState() off-audio-thread, commitAudioSessionState() audio-thread only; the audio thread reads a lock-free double-buffered LinkSnapshot stamped CLOCK_MONOTONIC, extrapolated at session tempo.
  • setTempo rewrites EVERY peer; imposeTempo(bpm) is the unconditioned version + only writer of weOwnTempo; never gate linkSpeedRatio on it. Match tempo by read RATE (linkSpeedRatio=linkBpm/recordedBpm -> effSpeed); imposeTempo() republishes in the same call or the finish edge doubles the take. It latches g_ownedBpm, re-imposed by controlTick() on every peer count settling kPeerSettleTicks=2 ticks (~400 ms) on join/leave — else a joining peer merges its own 120.000 session and eff_speed settles at 1.0067. resetTempoAuthority() clears it.
  • CLOCK-ONLY: tempo+phase shared, transport never. midi_clock.cpp never emits 0xFC; aloop IS the mesh’s sole transport emitter, so publishTransport must use setIsPlayingAndRequestBeatAtTime (stop keeps plain setIsPlaying) and applyRemoteTransport must reset m_lastRemotePhaseMicroBeats to -1 when arming m_remoteStartPending. 24-PPQN out has NO sink here: the only rawmidi is midiC1D0 = APC Key 25, excluded as a control surface, so outs.count == 0 and MidiClock::run() skips every pulse — the re-anchor guard firing 0 times is CORRECT. Witness: [midi-clock] started, no sending clock to.
  • Local transport never stops: a paused looper is MUTED, not stopped. ApcGrid::updateLocalTransport starts it once, never reports stopped; g_localTransportRunning defaults true.
  • Phase trim applies to masterPhaseSamples ONLY (kLinkPhaseTrimPerSample=0.00005, clamp kLinkPhaseTrimMax=0.03, ZEROED unless linkVarispeedEngaged && !manualPunchActive, else 51-cent detune). masterPhaseBuf ramps per-sample (never std::fill()) at masterPhaseSlope=linkSpeedRatio+linkPhaseTrim; effSpeed = g_manualSpeedMul*linkSpeedRatio carries TEMPO alone, while masterPhaseSamples advances at linkSpeedRatio ALONE. resyncCoeff closes the residual, ~42 ms time constant; tempo must hold kTempoStableBlocksThreshold = sr/N blocks, measure ~6 s after a jump.
  • Our material never moves for Link: the session moves to us. Only idle grid snap remains (!anyAudible); a join IMPOSES our phase (requestPhaseImpose(...) -> forceBeatAtTime off-thread) at circular error > kJoinSnapErrBeats=0.25. wasLinkDriving/wasLinkSynced clear when Link stops driving, so a reconnect reads as a join.
  • A take born at grid 0 (masterJustCreated): grid pinned 0, beat 0 forced on the session at that instant.
  • peers=0 lied: 12 straight polls were two host link-peer-sweep.exe processes seeing each other ([peer] peers=1 / [link] peers now 2); killing the duplicate gave peers=1 synced=true bpm=120 instantly — kill duplicates before trusting peers=0.

Audio thread and ALSA

worker() opens two PCMs: instrument (default hw:0,0) tight-latency blocking capture+playback; OTG gadget (f_uac2) best-effort NONBLOCK MIRROR (-EAGAIN expected), MASTER never cue. Instrument S32_LE only (divisor 2147483648.0f). period_size = block_size; start_threshold = one period; 4 periods min; f_uac2-gadget.sh req_number = 4. instrument_device is NOT the config literal: instrument_device_match (default AIR 192) substring-matches /proc/asound/cards at EVERY open; mis-resolution opens the control surface as the instrument silently. block_size=64 on device (latency_bias 322.2).

Resolve string-keyed lookups ONCE: control WRITE + telemetry READ cache (ParamStore slot, Faust zone float*) at startup; targetToZone() needs a case per control target (missing => "", silent). Recording taps loop.dsp prevFiltIn fed from prevFiltOut; Sampler::captureBlock reads prevFiltOut, never fin.

SHIFT (fx/monitorfold) fold is a CROSSFADE: fin[i] = fin[i]*(1-combinedFold) + prevLoopSum[i]*combinedFold, combinedFold = min(1, foldGain+glitchFoldGain); both ramp at kFoldStepPerSample = (1/16)/N. Three consumers differ: Faust zones take ramped gains, freeXposeBuf a RAW monitorFoldVal > 0.5 threshold, loopDirectGateNow a one-pole at kLoopDirectPole=0.9355.

Latency bias is MEASURED. snd_pcm_delay: capture after readi, playback before writei; capDelay + playDelay + N averaged over a 4 s window -> latency_bias_samples = N + roundTripEst + trim. MUST be a window average, never a fast EMA (pollHolds rewrites latencybias whenever it moves, so each wobble yanked every read head). latency_trim_samples in [audio]; /run/aloop/latency_trim polled on the control tick; unmeasured => kBlockSize.

Resample (SHIFT) bias is DERIVED, never constant. D_fold = 2N, D_dry = N + roundTripEst = shipped latency_bias_samples. Bias = round(D_dry*(1-f) + (2*blockSize + L_chain)*f); f = mean combinedFold over the take (PREVIOUS block’s fold), windowed ARM->FINISH; unwindowed => shiftHeld ? 1 : 0. L_chain = 128*engagedFraction + 128*shiftFraction; engagedZone is written 1, never cleared, so the shift term tests |SEMIS|>0.01. Telemetry resample_fold/resample_chain; [diag-latency] logs at FINISH when f > 0.01. Tolerance kToleranceSamples ±16; the intra-take sawtooth (~±170) no scalar removes.

Faust DSP

Language gotchas

  • & binds tighter than >/<: unparenthesised comparisons are silently always true.
  • par()-replicated UI controls RE-ELABORATE per call site (duplicated even hoisted); thread as a plain signal input.
  • No runtime branching: select2/ba.if choose among ALREADY-COMPUTED signals. Hence Guitar/LofiFx are a permanent Core-3 LV2 bundle, cost FLAT in held voices.
  • Recursion is namedStep ~ _: Faust takes no lambda left of ~. Two mutually-referencing recursive signals must BOTH be delayed (x', y') or the evaluator hits “stack overflow in eval”.

Compiler flags

-vec -fun -dfs -vs 32 -nvi -ct 0 at every real faust invocation; -mcpu=cortex-a72 at target-compile steps only; -O3, no -Ofast/-march=native/-mapp/fast-math/-mem/-vs 16. Not shipped: -mapp (aarch64 SIGSEGV), -fm def, ba.tabulate, per-effect LV2 splitting, -omp/-sch (fights pthread_setaffinity_np), -mcd/-dlt, -clang.

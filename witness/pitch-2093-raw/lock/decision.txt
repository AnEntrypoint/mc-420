DECISION: NO VARIANT ADMITTED. pitchtracker_ac.dsp unchanged.

Harness
- Tracker value per file = median of valid trace samples with t >= 1.0 s (traces/trace_<variant>_<name>.txt; new variants traces/trace_c2100_*, c2150_*, c2200_*, c2150_q2_*).
- Held note n0: explicit for named tones (sine_* = its frequency, flute/glock/piano/crotale/violin C7 names = 96, piano_mid_C4 = 60, piano_low_A1 = 33); all other files = nearest MIDI to the BASE settled tracker value (fixed across variants).
- Lock render: lock/dsp_cli_const_gen.cpp built with -I tools/dsp-cli; --gen0 source --gen4 const:<trk>:6 --gen5 const:<n0>:6 --gen6 const:1:6 out.wav; then --pitch out.wav from=0.4 to=1.4 hz=<440*2^((n0-69)/12)>.
- lock/prep.mjs (medians), lock/run.mjs (lock renders), lock/analyze.mjs (gates). lock/lock_results.tsv = every render; lock/analysis.txt = gate report.

Baseline discrepancy (must be resolved before any flute_trill claim)
- lock/table.txt reports flute_trill_high_C7 base lock 2097.46 Hz (+3.7 c) at tracker 1072.614.
- This harness does NOT reproduce it: tracker 1068..1225 Hz (all values in the trace) gives 3672..4212 Hz, +973..+1211 c, ncc 0.965..0.999. Base median 1085.37 gives 4145 Hz (+1182.9 c).
- Reproduced: sine_2093 (2010.84, -69.3 c), flute_high_C7 (3237.3, +755 c).
- Consequence: the flute_trill baseline is an octave-up lock error in this harness, so the flute_trill gate is measured against a broken baseline.

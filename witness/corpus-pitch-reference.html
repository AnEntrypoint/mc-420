Corpus pitch reference

Measured peaks for the files the pitch gate uses. A filename-derived note is NOT evidence of a file’s pitch; measure before using one as a target.

Method

48 kHz mono wav, 16384-sample Goertzel windows, non-overlapping, first 6 s, power summed across windows, peak picked on a log-spaced grid from 40 Hz to 4000 Hz at 0.5 percent steps (about 8.6 c resolution). Sub-multiple test: if the power at peak/2, peak/3 or peak/4 is within 12 dB of the peak, the lower frequency is taken instead. h2 and h3 are the second and third harmonic margins in dB below the chosen peak - a large negative margin means the peak really is the fundamental.

Witness: .gm/witness/corpus-pitch-reference.txt. Cross-checked against an independent power-averaged FFT with Hann windows at 50 percent overlap and parabolic interpolation (the two agree: sax 1049.1 here vs 1051.5 there, marimba C5 559.6 vs 558.9, cello 111.8 vs 111.6).

Files whose names contain _run_ or _scale_ are phrases rather than single notes, and a highest-average-power method reports a dominant pitch for them, not the note a gate asks about. A <note><octave><note2><octave2> range name is not proof of a single note either: marimba_mid_C5B5 carries that shape and is a four-note run (see the note above), so measure any range-named file before using it as a single-note target. vibraphone_mid_C5B5 had only 3 voiced windows here, so treat it as usable but soft.

tools/pitch-reference/submultiple.mjs runs the same method as this file (16384-sample non-overlapping Goertzel windows, power summed, log grid 40-4000 Hz at 0.5 percent steps) with the sub-multiple test extended from /2../4 to /2../8, and prints the harmonic ladder at whatever it finds. On trumpet_low_A3 it reproduces the 1091.84 Hz peak exactly. The only sub-multiple landing in 200-240 Hz is peak/5 = 218.368 Hz, and its local maximum is 218.40 Hz at 19.1 dB below the peak, which is outside the 12 dB margin above, so this file stays excluded. The exclusion is a limitation of the margin, not evidence against the fundamental: the ladder at 218.40 Hz is complete and brass-shaped, H1 -60.1, H2 -47.9, H3 -47.5, H4 -42.3, H5 -41.2, H6 -40.0, H7 -42.9, H8 -45.7 dB, with H6 the strongest and H1 the weakest, and no partial below the band floor plus 12 dB. So the true fundamental is 218.40 Hz (-12.9 c against the A3 label) and a method that tests the whole harmonic series instead of the peak’s own level would certify it. Witness: .gm/witness/trumpet-a3-extended-submultiple.txt.

bassoon_low_C2B2, violin_low_sulG_G3B3 and oboe_mid_C5B5 are the same failure class - a partial or a harmonic tie beating the fundamental - so a whole-series test would likely move them too. Until it exists, 8 of 34 files are scoreable and the gate measures what the reference can certify, not what the tracker can hear.

Comb certification (archive#corpus-comb-certification)

tools/pitch-reference/comb.mjs scores every candidate f0 on a log grid by the power summed at k*f0 for k = 1..8, penalised 12 dB per partial that falls below the spectrum median plus 12 dB, and takes the LOWEST candidate within 3 dB of the best score. Lowest-wins is what makes it a comb and not a peak finder. A candidate with no energy at its own f0 is rejected outright: that one rule is what kills the sub-octave candidates, which otherwise score almost as well as the true fundamental because their even multiples land on the real harmonics.

Run: node tools/pitch-reference/comb.mjs --phrase marimba_mid_C5B5,vibraphone_mid_C5B5, witness .gm/witness/corpus-comb-certification.txt.

Against the Reliable table it reproduces 7 of 7 non-phrase entries within 6.2 c (piano 262.61 vs 262.22, marimba_low 65.31 vs 65.21, cello 111.36 vs 111.76, trumpet_high 1045.45 vs 1049.13, soprano_sax 1050.68 vs 1049.13, clarinet 1045.45 vs 1049.13, marimba_mid 557.67 vs 559.64).

Rule

A gate that scores pitch against a target note must either use a measured peak from this table, or record the measurement it used with the run. Do not take the note from the filename.
